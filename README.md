# نظام إدارة معرض أولاد وليم

واجهة أولية عربية لإدارة معرض أجهزة كهربائية، تشمل المنتجات والمخزون والعملاء والمبيعات النقدية والتقسيط وملخصات وتقارير.

## التشغيل
افتح `index.html` في المتصفح أو انشر الملفات على GitHub Pages.

## تنبيه مهم
هذه نسخة تجريبية Front-end فقط. البيانات محفوظة في LocalStorage على نفس المتصفح والجهاز. لا يوجد حتى الآن تسجيل دخول حقيقي أو مزامنة بين الموظفين أو قاعدة بيانات سحابية أو نسخ احتياطي. لا تستخدم بيانات عملاء حقيقية أو تعتمد عليها محاسبياً قبل بناء Backend آمن وقاعدة بيانات وصلاحيات مستخدمين.

## التقنيات
HTML, CSS, JavaScript
